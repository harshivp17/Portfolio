SILENT PATH

SOLO PROJECT

THE MISSION

Designed and developed an atmospheric storytelling walking simulator focused on rich environmental storytelling, immersive soundscapes, and photorealistic level design.

TECHNICAL SPECS

  • ▶ ENVIRONMENT & LIGHTING: Developed using UE5 Lumen global illumination, custom Post-Processing Volumes, and volumetric fog.
  • ▶ AUDIO SYSTEM: Implemented dynamic, multi-layered soundscapes using Sound Cues with location-based distance attenuation (for ambient sounds and voice acting).
  • ▶ BLUEPRINT SCRIPTING: Built player trigger zones to dynamically control environmental dialogues and audio transitions.
